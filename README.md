## 常见问题

**Hinet VDS 和 VPS 有什么区别？**
VDS 强调资源独享程度更高，VPS 是更宽泛的叫法。放到这个具体产品上，实质区别不在名字，在 IP：这台机器给的是中华电信 HiNet 家宽拨号段的住宅 IP，不是机房段地址。

**动态 IP 会自己定时变吗？**
不会。这里的「动态」指的是 IP 来源属于家宽动态池、可以更换，不是每次拨号自动轮换。你需要主动发起更换，具体走工单还是面板，见上一节。

**能解锁 Netflix 台区、动画疯、TikTok 吗？**
官方页面列出的场景包括台湾 TikTok、台区游戏、ChatGPT、FB 与 WhatsApp 营销、亚马逊电商，以及 Netflix、Disney+、动画疯。住宅 IP 在流媒体识别上通常比机房段更干净。但具体某个 IP 在某天的解锁状态会随平台规则变化，开通后自己验一遍最实在。

**大陆直连能不能跑？**
能跑，但不保证体验。官方说法是「联通和部分地区移动直连速度不错」，电信用户和晚高峰时段建议走香港或日本中转。开 BBR 是必须做的优化。

**能不能装 Windows？**
官方在售页面标注支持安装 Windows。不过公开的第三方测评里没有对应的实测记录，如果你打算跑 Windows 桌面、多开环境或特定 Windows 软件，下单前向客服确认镜像和授权方式，别默认开箱就能用。

**只买一台够做多账号吗？**
一个 IPv4 意味着一台机器只有一个出口。多账号要么在这一个 IP 上做环境隔离，要么开多台实例拿多个 IP。后者成本是线性增长的，先算清楚再下单。
